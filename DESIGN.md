# Windows XP Olive desktop

## Direction

My startpage matches my dark HyDE Windows XP Olive theme. The top taskbar, cat Start button, bevelled controls and compact title bars are deliberate references to that desktop. Windows sit on the left at 1920 × 1080 so the cat remains visible on the right.

## Palette and type

- Main surface: `#252c20`.
- Taskbar base: `#303b25`.
- Active olive: `#526b38`.
- Main text: `#eeeedd`.
- Title text: `#f6f3df`.
- Readable accent: `#b7ca8b`.
- Bevel highlight: `#687b50`; shadow: `#29341e`.
- Tahoma, Liberation Sans and Arial for controls; Liberation Mono and Consolas for notes.

These colours come from my local HyDE and Waybar theme. Keep the olive desktop frame when changing the content colour preset. Controls use small corner radii, one-pixel borders and inset highlights rather than rounded floating panels. Default window opacity is 97%, with no blur.

## Layout and behaviour

The 37px top taskbar contains Start, Show desktop, window buttons, utilities and the clock. Desktop shortcuts restore their windows. Title-bar minimise buttons hide windows; taskbar buttons restore them. Show desktop hides the windows and footer, and pressing it again restores the previously visible windows.

Search spans two columns. Six utility windows occupy three rows with 24px to 28px gaps. The arrangement settings retain the existing saved order. Shorter screens scroll; screens below 600px use one column and a horizontal shortcut strip.

The cat wallpaper and Start icon are bundled locally. An uploaded background takes precedence. The first visit applies the XP appearance once and stores the previous appearance values; subsequent colour choices persist. Notes, favourites, pictures, conversations and other content keep their existing storage.

## Interaction details

Every desktop control performs a real action. Preserve keyboard search, note editing and chat shortcuts, visible focus outlines, labelled controls and reduced-motion support. Keep titles and button labels short and ordinary. Utility panels use the same title bars and inset fields as the main windows.
