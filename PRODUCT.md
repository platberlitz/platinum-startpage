# Startpage

## Register

product

## Users

My personal browser startpage on a HyDE Linux desktop, primarily at 1920 × 1080. I use it to search, open favourite sites, check clocks and weather, take notes and read news.

## Product Purpose

Keep everyday browser tools within reach, with local notes, links, pictures and preferences surviving a refresh. The desktop-style rearrangement and bundled HyDE cat wallpaper were explicitly chosen for this redesign.

## Brand Personality

Familiar, compact and playful. Match my dark Windows XP Olive desktop, including the top taskbar, cream text and cat details. Keep enough space between windows to see the wallpaper.

## Anti-references

Avoid a generic rounded dashboard, purple accents, oversized controls and decorative glass panels. XP-style controls should perform real actions rather than pretending to be working desktop buttons.

## Design Principles

- Put search and favourite sites within immediate reach.
- Use familiar desktop controls with clear labels.
- Retain existing notes, links, uploads and configuration.
- Make the desktop recognisable without covering the cat wallpaper.
- Keep settings and secondary tools accessible from the taskbar and Start menu.

## Accessibility & Inclusion

Use readable text, visible keyboard focus, labelled controls and reduced-motion support. Keep the existing keyboard shortcuts and make the layout usable in smaller browser windows.
